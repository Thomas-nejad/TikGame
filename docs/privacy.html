Privacy at Loop

Personal game demo · Updated 3 November 2026

This page explains what this version of Loop does with data.

Your game progress

The game uses your browser's local storage to remember personal bests, completed rounds and saved games. These records are stored on your device under loop-progress. Loop's game code does not upload those records to a server. You can remove them by clearing this site's data in your browser settings. Clearing data resets your records on that device.

Daily play and offline files

A local play streak records completed rounds on consecutive calendar days. Its last-play date, current count and best count are stored under loop-streak in this browser. They are not uploaded. Local clocks and clearing browser data can change the result.

After a successful online visit, a service worker can store this app’s public files in your browser cache for offline play. This cache is limited to Loop’s own folder. Clearing this site’s storage removes offline files and local records. The app offers installation help; installing is optional. Your browser may periodically request updated app files from GitHub.

Friendly challenge links

If you share a challenge, the link contains the game identifier and may include your personal-best score. Anyone you give that link to can see the challenge score. It is not a verified competitive result.

If your browser supports its native share sheet, you can choose an external app to receive the challenge link and game score. Sending through that app is your choice and is subject to its own privacy practices.

Hosting

This public demo is hosted on GitHub Pages. GitHub processes hosting requests and logs visitors' IP addresses for security purposes, including visits by people who are not signed in. See GitHub's hosting explanation and the GitHub General Privacy Statement for its practices.

Other services

This published build uses system fonts and does not load Google Fonts. Loop does not include advertising, analytics, account registration, chat or payment services. It does not set advertising or analytics cookies.

Project information

Source code and the public project owner's profile are available at Thomas-nejad/TikGame on GitHub.
